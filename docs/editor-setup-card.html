Signature Book — Editor setup

Photo Lounge by Redefined Weddings · the editing Mac at the wedding

One-time: install Booth Uploader

  1. Unzip Booth Uploader and drag it into Applications.
  2. First launch only: right-click → Open, then Open again (the app isn't App Store signed).
  3. It lives in the menu bar (camera icon); there is no Dock icon.
  4. Optional: menu → Launch at login.

One-time: Lightroom export preset

Export dialog → set these → Add preset named Photo Lounge Booth:

Export toSpecific folder → Choose folder later — pick tonight's watch folder at export time (see right)

Every event (2 minutes)

  1. Open the admin page → the event card → copy the Editor link. PIN is 0000 unless Andrew changed it.
  2. Make a fresh folder for tonight, e.g. Pictures / Booth Export / Sarah & Kai.
  3. Menu bar icon → Set up event… → paste the link, type the PIN and the couple's names, Choose… that folder → Start watching.
  4. In Lightroom, export with the preset into that same folder. Anything that lands there is uploaded, so keep it to tonight's booth photos.
  5. Upload the couple's Pic-Time QR on the editor page (Upload page → QR code) so guests can pre-register.

During the night

  1. Cull → quick edit → Export with preset. Each photo appears on the iPad within seconds.
  2. Menu bar shows Uploaded tonight, queue, and Last file.
  3. Wifi hiccup? Uploads retry on their own. Still failing → menu → Retry failed.
  4. Wrong photo? Editor page → hover the thumbnail → × → Delete.
  5. Watch who's signing in the editor page's Signed tonight feed.
Fallback: if the app isn't running, drag JPEGs straight onto the editor page's upload box. Same result.
